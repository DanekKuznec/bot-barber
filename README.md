# Бот записи в барбершоп — Telegram и ВКонтакте

Бот, через который клиенты записываются к мастеру, а администратор видит расписание и получает уведомления. Работает в Telegram и во ВКонтакте, расписание у каналов общее. Барбершоп «Фейд» вымышленный — это демо-проект для портфолио, все данные салона меняются в одном файле.

## Что умеет

**Для клиента**
- Запись за несколько нажатий: услуга → мастер или «любой свободный» → день → время → подтверждение.
- Показывается только реально свободное время: с учётом длительности услуги, графика мастера, уже занятых записей и того, что на сегодня нельзя записаться впритык.
- На каждом шаге можно вернуться назад и выбрать другое.
- Номер телефона — кнопкой «Отправить мой номер» (Telegram) или текстом в любом формате; бот приводит его к виду +7 (900) 123-45-67 и запоминает.
- «Мои записи»: список предстоящих визитов и отмена кнопкой в любой момент до визита; если клиент отменяет меньше чем за 2 часа, администратор видит пометку.
- Напоминания за сутки и за 2 часа до визита — в тот мессенджер, откуда клиент записался.

**Для салона**
- Одно расписание на оба канала: если клиент записался во ВКонтакте, это время сразу пропадает и в Telegram.
- Уведомление администратору о каждой новой записи и отмене — с именем, телефоном клиента и каналом.
- `/today` и `/tomorrow` — расписание по мастерам с пометкой, откуда пришёл клиент. Эти команды видят только администраторы.

**Надёжность**
- Двойная запись невозможна: проверка и сохранение идут в одной транзакции SQLite. Если двое подтвердили одно время одновременно, второй получит предложение выбрать другое, а при записи к «любому мастеру» бот сам попробует свободного коллегу.
- Кнопки из старых сообщений после перезапуска бота не ломают запись — бот предложит начать заново.
- Клиенты различаются по паре «канал + id», поэтому совпадение номеров аккаунтов в Telegram и ВК ничего не путает.
- Клавиатуры ВК собираются с учётом её ограничений (10 кнопок, 6 рядов, 40 символов), время листается страницами.

## Как устроен код

```
bot/
  catalog.py        услуги, мастера, часы работы и правила — всё, что меняется под салон
  slots.py          расчёт свободного времени (чистые функции)
  booking_core.py   логика записи, общая для обоих мессенджеров
  db.py             SQLite: клиенты, записи, напоминания
  texts.py          тексты и даты по-русски
  reminders.py      напоминания для любого канала
  handlers/         Telegram (aiogram 3): запись, мои записи, администратор
  vk/               ВКонтакте: клиент Bots Long Poll API, клавиатуры, диалог
  __main__.py       запуск каналов, для которых заданы ключи
tests/              23 теста: расчёт времени, база, сквозные диалоги в Telegram и ВК без сети
```

Стек: Python 3.11+, aiogram 3, aiohttp, aiosqlite.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # Windows: copy .env.example .env
```

Заполните в `.env` один канал или оба (инструкции ниже) и запустите:

```bash
python -m bot
```

### Telegram

1. У [@BotFather](https://t.me/BotFather) отправьте `/newbot` и скопируйте токен в `BOT_TOKEN`.
2. Свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)) впишите в `ADMIN_IDS` — туда будут приходить уведомления.

### ВКонтакте

1. Создайте сообщество (или возьмите своё, где вы администратор).
2. **Управление → Сообщения**: включите сообщения сообщества.
3. **Управление → Сообщения → Настройки для бота**: включите «Возможности ботов» и «Добавить кнопку „Начать“».
4. **Управление → Работа с API → Ключи доступа**: создайте ключ с правами на сообщения и управление сообществом. Ключ — в `VK_TOKEN`.
5. **Работа с API → Long Poll API**: включите, версия API 5.199. В «Типах событий» отметьте «Входящее сообщение» и «Действие с сообщением».
6. Числовой id сообщества (для `vk.com/club123456` — `123456`) впишите в `VK_GROUP_ID`.
7. Свой id ВК впишите в `VK_ADMIN_IDS` и напишите сообществу любое сообщение — без этого ВК не даст боту прислать вам уведомление.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
ruff check bot tests   # если установлен ruff
```

Сквозные тесты проходят диалог целиком — от «Записаться» до уведомления администратору — в обоих мессенджерах, с подменённым временем и без сети. На GitHub тесты и линтер (ruff) запускаются автоматически при каждом изменении.
